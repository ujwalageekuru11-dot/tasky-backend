# Tasky - Task Management Application

Tasky is a task management application developed using JavaScript and Node.js. This project has three versions, showing my learning journey from a command-line application to an Express.js backend.

## Project Versions

### V1 - Command-Line Task Manager
- Add tasks
- View tasks
- Delete tasks
- Menu-driven application

### V2 - File-Based Task Manager
- Add, view, and delete tasks
- Store tasks in a JSON file
- Use Node.js file system operations
- Use asynchronous programming

### V3 - Express.js Backend
- Build REST APIs using Express.js
- Organize code using MVC concepts
- Implement CRUD operations
- Handle HTTP requests and responses

## Technologies Used

- JavaScript
- Node.js
- Express.js
- readline-sync
- fs/promises
- JSON

## Learning Outcomes

- JavaScript fundamentals
- Node.js fundamentals
- File handling
- REST API development
- CRUD operations
- Backend project structure
